# SideStack

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

把桌面快捷方式收纳到屏幕左右两侧的隐藏式 Dock 面板 —— 桌面保持干净，需要时鼠标移到屏幕边缘就滑出来。

程序常驻**系统托盘**、不占任务栏、**不需要管理员权限**；面板支持经典玻璃 / 透亮 / 光感 / 光感·强 四种风格，
其中「光感」系列是纯 CPU 实现的液态玻璃（抓取面板背后的真实屏幕画面，做折射 + 色散 + 内阴影）。

## 功能

- **两侧隐藏式面板**：鼠标贴到屏幕最左 / 最右边缘即滑入，移开后自动收回；也可设为常显。
- **四种面板风格**：经典玻璃、透亮、光感、光感·强，图标圆角与单图标缩放均可调。
- **图标管理**：拖动排序、左右互换、拖入文件新增、右键移除 / 换图标 / 定位文件；桌面快捷方式增删自动同步。
- **自动让位**：独占全屏、无边框窗口化全屏、演示模式等真·全屏场景下自动隐身，退出后自动恢复；
  普通最大化窗口不会让侧边栏消失（贴边照常唤出）。
- **随系统启动**：可选开机自启（计划任务）与启动优先级；可顺带隐藏桌面图标。
- **不抢焦点**：面板是工具窗口，不占任务栏、不打断你正在做的事。

## 运行要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11 |
| 运行时 | .NET Framework 4.0 以上（Win10 自带 4.6+，Win11 自带 4.8.1，通常**无需额外安装**） |
| 隐私 | 全部功能在本机完成，不联网、不上传任何数据 |
| 权限 | 按用户运行，只读写 `%APPDATA%\SideStack\` 与 `HKCU` |

## 安装与使用

- **安装包**：`dist\SideStack-<版本>-x64.msi`，按用户安装到 `%LocalAppData%\Programs\SideStack`，无需管理员；
  卸载走「设置 → 应用 → 已安装的应用」。
- **免安装**：直接双击 `SideStack.exe`，启动后不显示窗口，只在托盘常驻。

使用要点：

1. 鼠标移到屏幕**最左 / 最右边缘**，对应侧面板滑入；移开后延迟自动收回。
2. 单击或双击托盘图标打开设置；托盘右键菜单里可开关面板、退出程序。
3. 面板上右键图标可换图标、调大小、左右互换或移除。

配置与日志位于 `%APPDATA%\SideStack\`（`config.txt`、`sidestack.log`，历史配置备份在 `backups\`）。

设置项的完整说明、每种面板风格的做法与实测开销、以及大量排障记录，见 **[使用说明.md](使用说明.md)**。
